### 5. ✅ Student Edit - Phone Number +20 Prefix Issue
**Problem:** When editing student, phone numbers show +20 prefix but form rejects it  
**Root Cause:** `_clean_phone()` method was adding +20 prefix on save  
**Fix:** Modified `_clean_phone()` to:
- Remove +20 prefix if present
- Store numbers starting with 0 (Egyptian format)
- Handle various input formats (with/without +20, with/without leading 0)

**Code Changed:**
```python
def _clean_phone(self, phone):
    """Helper to normalize phone numbers - removes +20 prefix for storage"""
    if not phone:
        return phone
    phone = phone.replace(' ', '').replace('-', '').strip()
    # Remove +20 prefix if exists
    if phone.startswith('+20'):
        phone = '0' + phone[3:]
    elif phone.startswith('20') and len(phone) == 12:
        phone = '0' + phone[2:]
    # Ensure starts with 0
    if not phone.startswith('0') and len(phone) == 10:
        phone = '0' + phone
    return phone
```

**Status:** ✅ Fixed
