**بعد التعديل**:
```python
def _clean_phone(self, phone):
    """Helper to normalize phone numbers"""
    if not phone:
        return phone
    
    # Remove spaces and dashes
    phone = phone.replace(' ', '').replace('-', '')
    
    # If already has +20, keep it as is
    if phone.startswith('+20'):
        return phone
    
    # If starts with +, assume it's correct
    if phone.startswith('+'):
        return phone
    
    # Add +20 for Egyptian numbers
    if phone.startswith('0'):
        phone = '+20' + phone[1:]
    else:
        phone = '+20' + phone
    
    return phone
```

**إضافة في __init__**:
```python

if self.instance and self.instance.pk:

        self.initial['parent_phone'] = '0' + self.instance.parent_phone[3:]
```

**بعد**:

```python
    teachers = Teacher.objects.filter(is_active=True).prefetch_related('subjects')
    return render(request, 'teachers/list.html', {'teachers': teachers})
```
